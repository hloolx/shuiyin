# 水印工具 · 需求拆解与优化方案（v1.0.2 → v2.0.0）

## 一、产品定位

- **一句话**：在浏览器本地给图片批量加文字水印，图片不出本机。
- **核心场景**：身份证 / 证件照复印件加「仅供 XX 使用，他用无效」（项目源自 [joyqi/sfz](https://github.com/joyqi/sfz)，sfz 即"身份证"），其次是作品图版权签名、内部资料防外传。
- **核心诉求**排序：① 隐私安全（不上传）② 水印难去除 ③ 操作快、所见即所得 ④ 批量 ⑤ 手机上也能用（包括微信内打开）。

### 非功能需求

| 维度 | 目标 | 落地方式 |
|---|---|---|
| 隐私 | 图片不离开设备 | 纯前端，无任何网络请求（SW 只缓存站点自身资源） |
| 性能 | 4000×3000 大图拖动滑块不掉帧 | 预览按屏幕像素渲染、底图缓存、只重绘水印 |
| 内存 | 批量几十张不崩溃（尤其 iOS） | 原图 LRU 缓存 3 张、导出逐张处理即释放、iOS 画布面积上限保护 |

| 可访问性 | 键盘可用、读屏可读 | 原生 range 滑块、role/aria、焦点环、尊重「减少动态效果」 |
| 主题 | 跟随系统暗色 | CSS 变量主题 + 手动切换 + 首帧前注入避免闪白 |

## 四、优化方案

### 1. 渲染管线（解决 #1 #2 #3 #13）

```
文件 ──createImageBitmap──▶ 原图 (LRU 缓存 3 张)
                                │
         ┌──────────────────────┴───────────────────────┐
         ▼ 预览                                          ▼ 导出
 按「容器尺寸 × DPR」缩小一次 → 底图 canvas         原图尺寸 canvas（超 iOS 上限则等比缩小）
 （只在换图 / 窗口尺寸变化时重画）                  → toBlob(原格式/质量) → 写入 ZIP
         │                                         → 立即释放 canvas，处理下一张
 调参时：底图 + 水印 → 预览 canvas（rAF 合帧）
```

- 水印字号、间距都按**原图尺寸**计算再乘缩放比，预览与导出比例完全一致。
- 平铺算法改为以中心旋转、覆盖对角线圆，支持奇数行错位。
- 单个水印根据旋转后的包围盒计算位置，任何角度都不会超出图片。

### 2. 状态管理（解决 #4 #5 #11）

- 图片以 **id** 而不是索引标识当前图，`useReducer` 纯函数更新。
- 删除先移出列表、5 秒后才真正释放 object URL，期间可撤销。
- 缩略图串行生成，避免一次拖入几十张大图卡死页面。

### 3. 交互与布局（解决 #9 #10 #12 #14）

- **桌面**：图片列表 | 预览舞台 | 设置面板 三栏，整屏不滚动，各自内部滚动。
- **移动**：预览吸顶，下方缩略图条 + 设置，底部固定「保存当前 / 导出所选」。断点用 `matchMedia`，不再受地址栏伸缩影响。
- 预览舞台底部悬浮工具栏：上一张 / 序号 / 下一张 / 对比原图 / 查看大图 / 下载。
- 快捷键：`←/→` 切换、按住 `空格` 对比、`⌘/Ctrl+S` 下载当前、`⌘/Ctrl+Shift+S` 导出所选、`Delete` 移除。

### 4. 动效清单

统一使用 `motion`（Framer Motion），弹簧参数集中在几档；系统开启「减少动态效果」时自动降级。

| 场景 | 动效 |
|---|---|
| 首页 | 元素依次弹入；插画上水印文字缓慢漂移；拖拽区悬停上浮 |
| 首页 → 编辑器 | 侧栏从左滑入、设置面板从右滑入、顶栏下落、预览缩放淡入 |
| 拖入文件 | 背景模糊淡入，卡片弹出，虚线边框流动，图标上下浮动 |
| 图片列表 | 新增依次滑入，删除滑出并且其余项平滑补位；当前项高亮块在行间滑动 |
| 切换图片 | 按方向左右滑入 + 交叉淡化；手机端可跟手拖动，松手回弹或翻页 |
| 预览加载 | 骨架屏闪光，绘制完成后淡入 |
| 对比原图 | 「原图」标签下落淡入 |
| 设置面板 | 分段控件滑块、九宫格选中块、色块选中圈均为共享布局动画；切换平铺/单个时高度平滑展开 |
| 勾选框 | 勾号描边绘制动画 |
| 开关 | 弹簧滑动 |
| 导出 | 弹窗弹出，渐变进度条弹簧增长，完成时圆圈 + 勾号描边动画 |
| 通知 | 顶部弹入、堆叠自动补位，悬停暂停计时 |
| 主题切换 | 太阳 / 月亮图标旋转交替 |
| 移动抽屉 | 弹簧滑出，支持向左拖动关闭 |

## 五、实测对比

测试条件：同一张 4000×3000 JPG，Chrome 移动端模拟（390×844 @2x）+ **6 倍 CPU 降速**模拟中端手机，连续拖动滑块 40 次。

| 指标 | 原版 | 新版 |
|---|---|---|
| 40 次拖动总耗时 | 3151 ms | **787 ms** |
| 平均帧耗时 | 19.6 ms | **8.9 ms** |
| P95 帧耗时 | 90 ms | **21 ms** |
| 最长一帧 | 132 ms | **47 ms** |
| 超过 100ms 的卡顿帧 | 5 | **0** |
| 拖动期间内存增长 | +103 MB | **+15 MB** |
| 首屏 JS（gzip） | 114.6 KB | **111.4 KB** |

端到端交互检查 23 项全部通过（拖入、上传、非法文件提示、键盘切换、对比、删除撤销、单个水印、颜色校验、大图原始分辨率、下载格式、ZIP 内容与 JPG 体积、暗色模式、设置持久化、移动端滑动切换、吸顶、抽屉、保存查看器），控制台零报错。
